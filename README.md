
🐾 Laço — Plataforma de Adoção de Animais
"Uma ponte digital entre o carinho de quem resgata e o desejo de quem quer adotar."

O Laço é uma aplicação web desenvolvida para facilitar o processo de adoção responsável de animais de estimação. A plataforma centraliza anúncios de pets, permitindo que potenciais adotantes filtrem, visualizem detalhes completos e entrem em contacto, além de oferecer uma área dedicada para utilizadores gerirem e publicarem os seus próprios animais.

🚀 Funcionalidades Principais
🏠 Página Inicial com Filtros: Exploração dinâmica de pets disponíveis com opções de busca e filtragem por espécie, nome ou cidade e faixa etária.

🔍 Modal de Detalhes Dinâmico: Exibição de informações completas do animal selecionado (história, características e fotos).

📱 Integração Simulada com o WhatsApp: Botão direto no modal para iniciar conversa instantânea sobre a adoção.

⭐ Sistema de Favoritos: Possibilidade de guardar os pets preferidos para consulta posterior no painel de perfil.

🔐 Controlo de Acesso (Autenticação Simulada).

👤 Painel de Perfil: Área restrita do utilizador para gerir favoritos, ver dados e navegar facilmente de volta ao início.

🛠️ Tecnologias Utilizadas
Este projeto foi desenvolvido com foco em boas práticas de programação modular e manipulação do DOM:

HTML5 & CSS3: Estruturação semântica e estilização responsiva.

JavaScript (ES6+):

Modularização de código (utilização de export/import, como o modal.js).

Delegação de eventos global.

Manipulação de dados com LocalStorage para simular uma base de dados local.

Vite: Ferramenta de build rápida para desenvolvimento web moderno.

Git & GitHub: Controlo de versões utilizando o padrão de Conventional Commits.

💻 Instruções de Instalação
Certifica-te de que tens o Node.js e o Git instalados na tua máquina antes de começar.

1. Clonar o Repositório
Abre o terminal do teu sistema ou do VS Code e clona o repositório:

Bash
git clone https://github.com/teu-utilizador/laco-adocao.git
2. Aceder à Pasta do Projeto
Entra na pasta que foi criada após o clone:

Bash
cd laco-adocao
3. Instalar as Dependências do Projeto
Executa o comando do npm para instalar todas as dependências (incluindo o Vite):

Bash
npm install
4. Executar o Servidor de Desenvolvimento
Inicia o servidor local do Vite executando:

Bash
npm run dev
5. Abrir no Navegador
Após executar o comando acima, o terminal irá exibir o endereço local onde o projeto está a correr (geralmente http://localhost:5173/).
Basta pressionar Ctrl + Clique no link do terminal ou copiá-lo e colá-lo no teu navegador.
